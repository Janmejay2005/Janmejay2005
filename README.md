A lightweight web application that converts complex **JSON data into human-readable explanations**.

The application supports JSON parsing, validation, file uploads, drag-and-drop input, automatic structure analysis, statistics and detailed hierarchical breakdowns.

**Tech:** JavaScript • HTML • CSS • JSON Parsing • DOM Manipulation
